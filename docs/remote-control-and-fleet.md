# Remote control and fleet

## Purpose

This planned product area is intended to give operators a coherent boundary
for remote leadership, control, and fleet-oriented surfaces.

## Planned boundary and interfaces

The planned boundary covers remote leadership, a Control-/Execution-Host or
remote target, and fleet surfaces. Its principal documented interfaces are the
control plane, resource monitor, and Home-broker boundary.

## Was heute dokumentiert ist

- [Control plane](control-plane.md)
- [Resource monitor](operations/resource-monitor.md)
- [Home-broker boundary](operations/the-hive-home-broker.md)

## Geplant

Remote leadership, a Control-/Execution-Host or remote target, and fleet
surfaces are planned. This page does not claim a remote service, connected
host, deployment, runtime, installation, or live user interface.
